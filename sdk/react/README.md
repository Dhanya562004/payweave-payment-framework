# PayWeave React Merchant Checkout SDK

Declarative React + TypeScript SDK for integrating PayWeave checkout flows into web applications.

## Features
- `<PayWeaveCheckout />` component powered by declarative merchant DSL configs
- Dynamic layout & theme customization (`compact`, `vibrant_fintech`, `dark_glass`)
- UPI Intent & Card payment flow simulation
- Saved payment one-click checkout
- Real-time provider fallback and retry indicators

## Local Demo Setup
```bash
cd sdk/react
npm install
npm run dev
```

## Build
```bash
npm run build
```
